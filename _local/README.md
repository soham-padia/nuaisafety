# _local

An untracked working directory. Nothing here is committed except this README.

This repository is public, because GitHub Pages requires it on a free plan. Use
`_local/` for anything that should not be: private notes, drafts, correspondence,
screenshots, and any material naming a person who has not agreed to be published.

Because the folder is gitignored it does not sync between machines or
collaborators, so back it up separately if it matters.
